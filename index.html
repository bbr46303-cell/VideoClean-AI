Frequently Asked Questions

Is VideoClean AI a copyright bypass tool?

No. It is intended for processing and optimizing videos that you own or have permission to edit. Re-encoding a file does not remove copyright ownership or platform rights.

Why does processing take time?

Video encoding is CPU-intensive. Short videos should generally finish faster, while resolution, filters and server resources can increase processing time.

Is my Razorpay secret key exposed?

No. The secret key must remain on the backend as an environment variable. Only the public Key ID is returned to the frontend.

Where is my processed video downloaded from?

The backend creates a unique job file and returns a download endpoint for that processed MP4.
